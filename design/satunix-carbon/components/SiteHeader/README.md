# SiteHeader

The site name in bold Helvetica on the left, bracketed lowercase mono navigation on the right.

## When to use
Top of every page, inside the container.

## Consumer provides
`name`, optional `href` (home), and `items`: `{ label, href, current }` with lowercase one-word labels.

## Rules
- Name `heading-04` in `text-primary`, `accent` on hover.
- Nav `label-01`, `text-secondary` at rest, `accent` on hover and on the current page. Brackets are aria-hidden.
- `spacing-07` above and below. No bar, no fill, no rule under it.
