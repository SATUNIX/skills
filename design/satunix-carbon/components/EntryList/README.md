# EntryList

Numbered entries: a mono index and status in an `index-column` on the left, title, summary and a compact "covers" list on the right.

## When to use
Work history and project lists, where order matters and each item has a summary.

## Consumer provides
`entries` (`title`, `summary`, optional `status`, `tagline`, `items`, `href`) and `itemsLabel` ("covers", "themes").

## Rules
- Entries `spacing-10` apart; no dividers.
- Title `heading-05`, summary `body-02`, meta `label-01` in `text-secondary`.
- Below 40rem the index moves onto one line above the title.
