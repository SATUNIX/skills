# SectionHead

A numbered section heading: a mono index label ("01 / writing") over a large Helvetica title.

## When to use
To open each major section of a page. Sections are separated by space (`spacing-10`), never by rules.

## Consumer provides
`label`, `title`, optional `index` (two digits), `id`, and `as` for the heading level.

## Rules
Label `label-01` in `text-secondary`; title `heading-06`. `spacing-03` between them, `spacing-07` below.
