# Logos

- `favicon-mark.svg`: the "#" mark: a bold monospace `#` in `brand-lime` (#c2fe0b) on a `gray-100` (#161616) square, 32×32. Used as the favicon and app icon. Two fixed inks, not recolourable; don't place it on lime.

There is no wordmark file. The name is set in type: Helvetica Bold (`heading-04`) in the header, and as a shaded ASCII banner in JetBrains Mono on the homepage.
